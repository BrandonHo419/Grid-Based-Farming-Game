# Credits and provenance

This project is Brandon Ho's subsequent rebuild of the university group project
[GridFarmGame / MajorPracticalProjectOOP](https://github.com/BrandonHo419/GridFarmGame).
The original project was collaborative; this rebuild does not claim sole
authorship of that work. See the original repository and its contributor history.

Milestone 1 contains newly written code and geometric placeholders. No original
source files, sprites, fonts or audio have been copied. Individual contributor
names and asset permissions must be verified before reusing original material.
No licence for the new application has been selected yet.
